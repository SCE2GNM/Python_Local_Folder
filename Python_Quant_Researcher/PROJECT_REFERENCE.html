1 — Project Overview

What this is: A systematic quant trading curriculum running over 24 weeks. Each week builds one skill layer — from basic backtesting through live execution, portfolio management, DeFi protocols, ML signal generation, and eventually HFT infrastructure.

Operating model: Strategies are researched in Claude Chat (web search enabled), built and backtested in Claude Code (this environment), and deployed as cron-triggered Python bots on EC2. Every strategy goes through a 6-phase research pipeline before capital is committed.

Live trading context: Three strategies have reached deployment decision. Two are funded and running on EC2 (ETH ADX live, ETH RSI in validation). BTC SMA has a CONDITIONAL GO decision but is unfunded pending capital constraints.
